Context

End User

University students, roommates, and friend groups who share living expenses, groceries, utilities, or travel costs.

Problem

Tracking shared expenses and settling debts manually is tedious and error-prone. Friends avoid discussing money to prevent awkward conversations, leading to unresolved debts.

Solution

A web app that automatically calculates who owes whom after shared expenses among friends, with invite-based group joining and personal payment details.

Implementation

Version 1
  • User registration and login
  • Create expense groups with invite codes
  • Add expenses with custom splits
  • Automatic debt calculation algorithm
  • React and Bootstrap web UI
Version 2
  • Join groups by invite code
  • Personal profiles with payment details
  • Mark as Paid with payment history
  • My Debts tab - personalized view
  • Docker Compose deployment
